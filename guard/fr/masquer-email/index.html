📧 Obfuscation d'email

Protégez votre adresse email des bots de spam

1️⃣ Remplacement de texte
Remplace @ et . par du texte — lisible par les humains, pas par les bots
2️⃣ Entités HTML
Convertit les caractères en codes HTML. Les navigateurs les affichent normalement
3️⃣ Méthode JavaScript
Assemble l'email via JS. L'email n'apparaît pas directement dans le code source
4️⃣ Inversé + CSS
Inversion CSS direction. Apparence normale à l'écran, inversé dans le code
5️⃣ Remplacement de symboles
Utilise des symboles spéciaux — non copiable par les bots
💡 Pourquoi obfusquer votre email ?
• Publier votre email sur un site web permet aux bots de le collecter automatiquement
• Les emails collectés reçoivent un flot de spam/phishing
• L'obfuscation permet aux humains de le lire mais les bots ne peuvent pas le collecter
• Indispensable pour les blogs, portfolios et CV !
