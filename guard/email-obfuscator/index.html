📧 이메일 난독화

스팸봇으로부터 이메일 주소를 보호하세요

1️⃣ 텍스트 치환
@와 .을 텍스트로 바꿔서 사람은 읽을 수 있지만 봇은 수집 못함
2️⃣ HTML 엔티티
문자를 HTML 코드로 변환. 웹페이지에 삽입하면 브라우저가 복원
3️⃣ JavaScript 방식
JS로 이메일을 조립. 소스코드에 이메일이 직접 노출되지 않음
4️⃣ 거꾸로 + CSS
CSS direction으로 거꾸로 쓰기. 화면에선 정상, 소스에선 거꾸로
5️⃣ 이미지 대체 텍스트
그냥 이렇게 쓰세요 (복사 불가 = 봇 수집 불가)
💡 왜 이메일을 난독화해야 하나요?
• 웹사이트에 이메일을 그대로 쓰면 스팸봇이 자동 수집
• 수집된 이메일로 스팸/피싱 메일이 쏟아짐
• 난독화하면 사람은 읽을 수 있지만 봇은 수집 불가
• 블로그, 포트폴리오, 이력서에 이메일 올릴 때 필수!
