💡 어떻게 작동하나요?
첫글자 추출: 문장의 각 단어 첫 글자 + 숫자 + 특수문자 조합
혼합 변환: 문장을 압축하고 대소문자/숫자/특수문자 혼합
Leet 변환: 알파벳을 숫자/기호로 치환 (a→@, e→3, s→$)
"나는 2024년에 서울에서 살고 있다"
→ 첫글자: N2e$eSs!
→ 혼합: Na24$eUl#sG
→ Leet: n@2024$30uL!
🧠 왜 문장 비밀번호가 좋은가요?
• 기억하기 쉬움 — 랜덤 문자열보다 문장이 기억에 남음
• 길고 복잡함 — 문장에서 추출하면 자연스럽게 길어짐
• 나만 아는 것 — 개인적 문장은 사전 공격에 안 걸림
• 사이트마다 다르게 — 문장 끝에 사이트 이름 넣으면 각각 다른 비번
