# MOGU 수익 모델 최종 (2026-09-30)

## 수익 구조 (확정)

### 현금 수익 (2가지만)
1. **광고 (Google AdSense)** — 수익 90%
   - 페이지 입장 전 전면 광고 1번 (사주앱 구조)
   - 페이지 안에서는 광고 없음 = UI 깔끔
   - 모구문 + 모구팔 + 모구월드 3개 사이트 전부
2. **MOGU Pass ($2.99/월, $24.99/년)** — 수익 10%
   - 광고 제거 전용
   - 캐쉬 아이템 아님, 광고 싫은 사람용

### 무료 재화 (파편 = 노력/시간 투자)
- 코디 아이템 (왕관, 리본, 선글라스 등) → 파편으로 구매
- 확성기 → 파편으로만 구매 (현금 X, 이상한놈 필터)
- 부스트 → 파편으로 구매
- 파편 획득: 게임 승리, 출석, 활동 등

### 현금 캐쉬 아이템 = 없음
- 확성기, 코디, 부스트 전부 파편(무료 재화)으로만
- 과금 압박 없는 깨끗한 구조
