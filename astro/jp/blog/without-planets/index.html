もし他の惑星がなかったら？

(全ての内容は個人的な意見です。反論があればあなたが正しい 'ㅅ')

太陽がある。地球がある。月がある。

でも宇宙にはもっと隣人がいる。

水星、金星、火星、木星、土星、天王星、海王星。

全部同じ太陽の周りを回っているらしい。

別に何かをしてくれているわけでもなさそうだ。ただ遠くで回っているだけだ。

でももし、こいつらがいなくなったら？

木星

木星は太陽系で一番大きいやつだ。

この巨大な友達は — 宇宙から飛んでくる岩をかわりに受け止めてくれているらしい。

木星がなかったら？地球に向かってくる岩がずっと増えるらしい。

木星は地球のボディーガードだ 'ㅅ'

土星

木星が太陽系で一番大きいと言ったけど..こんなに大きいやつが一人でいると危険らしい。力が強すぎて周りの惑星の軌道を全部揺さぶってしまうらしい。

土星が外から木星を抑えているらしい。

土星がなかったら？木星が一人で暴走して、地球が回る道がめちゃくちゃになるかもしれないらしい。

ボディーガードにもパートナーが必要なんだ 'ㅅ'

金星

金星は地球とほぼ同じ大きさらしい。

金星がなくなると地球が太陽の周りを回る道が少し変わるらしい。

道が変わる → 太陽との距離が変わる → 温度が変わる → 天気が変わる → 動物が変わる → 全部変わるらしい。

一つが変わると次々と変わっていく。

そうしたら生き物の姿も今私たちが知っているこの姿じゃないかもしれない =ㅅ=...?

火星

火星がなくなってもすぐには大丈夫らしい。

でも火星と木星の間に岩がたくさん漂っているらしい。火星もこいつらを抑えるのを助けているらしいけど。火星がなかったら岩があちこちに飛び出してくるらしい。

そして火星は将来人類が引っ越せる一番近い候補らしい。

火星も木星との小さなパートナー 'ㅅ'?

天王星、海王星

一番外にある惑星たちだ。

太陽系の端っこで氷の塊が内側に入ってこないように防いでいるらしい。

こいつらがいなかったら外から氷の塊がどんどん飛んでくるらしい。

なんかアイスミサイルを防いでくれる魔法の盾みたい =ㅅ=...?

水星

水星は太陽に一番近い惑星だ。

なくなっても地球への直接的な影響はほとんどないらしい。

でも面白いのが — アインシュタインが自分の理論が正しいことを証明するときに水星を使ったらしい。水星がなかったら物理学の歴史が変わっていたかもしれないらしい 'ㅅ'

そしてこれは私の考えなんだけど..太陽はとても熱い存在だ。なのに水星は水の気を持つ惑星 =ㅅ=...?

全部役割がある

木星 = ボディーガード。
土星 = 監視者。
金星 = バランス。
火星 = 岩の管理。
天王星、海王星 = 外の警備。

一つでも欠けると地球が危なくなるらしい。

でも名前がちょっと不思議だ

古代の人たちが惑星に名前をつけた。

木星 = ゼウス。王。守護者。
土星 = クロノス。秩序。規律。
火星 = アレス。戦争。
金星 = アフロディーテ。美しさ。

でも名前と実際にやっていることがそっくりすぎる。

木星は本当に守っているし。土星は本当に秩序を保っているし。火星は本当に岩と戦っているし。

どうやって知っていたんだろう 'ㅅ'?

知らなかったのか

普通「昔の人は科学を知らなかった」と言う。

でも。

バビロニア人は日食を数十年前に予測したらしい。

マヤ人は金星が太陽を一周する時間を2時間の誤差で計算したらしい。望遠鏡なしで。

これが「知らなかった」人たちのやったことだ 'ㅅ'

日食と月食は太陽と地球と月が一直線に並んだときに起きる現象だけど..

これはタイミングの問題とも言える。

でもこのタイミングを当てるには太陽がどう動いて月がどんな速度で回って地球がどこにいるかを

全部知らないといけない。

でも古代人がこれを =ㅅ=.....?

数千年

昔の人たちは毎晩空を見上げていたらしい。

そして記録したらしい。数千年間も。

木星がここにあるとき国が平和だった。土星がここにあるとき辛いことが起きた。火星がここにあるとき戦争が起きた。

私はたまに夜空を見上げる。

あそこに見える明るい点一つひとつが。全部理由があってそこにいるんじゃないかな 'ㅅ'?

とにかく不思議だ。本当に不思議 'ㅅ'
