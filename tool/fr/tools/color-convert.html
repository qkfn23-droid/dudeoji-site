Guide des formats de couleur

HEX — Code couleur hexadécimal. Ex : #FF5733. Le plus utilisé en HTML et CSS.

RGB — Rouge (R), Vert (G), Bleu (B) chacun dans la plage 0~255. Ex : rgb(255, 87, 51).

HSL — Teinte (H, 0~360°), Saturation (S, 0~100%), Luminosité (L, 0~100%). Pratique pour ajuster intuitivement les couleurs.
