Qu'est-ce qu'une base numérique ?

Une base numérique (système de numération) est une méthode de représentation des nombres, distinguée par le nombre de symboles utilisés. Les ordinateurs utilisent en interne le système binaire, et l'hexadécimal est utilisé pour le représenter de manière concise.
