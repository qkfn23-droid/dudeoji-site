Mode d'emploi

Sélectionnez le type d'unité dans les onglets ci-dessus.
Choisissez l'unité source dans le menu déroulant de gauche et l'unité cible dans celui de droite, puis saisissez un nombre pour obtenir le résultat instantanément.
Appuyez sur le bouton ⇄ pour inverser les deux unités.
