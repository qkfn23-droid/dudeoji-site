Calculatrice de Pythagore

Calcule l'hypoténuse ou le côté manquant d'un triangle rectangle avec le théorème de Pythagore (a² + b² = c²). Entrez deux côtés pour trouver le troisième.

Comment ça marche

  • Trouver l'hypoténuse — Entrez les côtés a et b : c = √(a² + b²)
  • Trouver un côté — Entrez l'hypoténuse c et le côté a : b = √(c² - a²)

FAQ

Quand utiliser le théorème de Pythagore ?

Architecture, ingénierie, navigation, développement de jeux — chaque fois que vous devez calculer la distance entre deux points.
