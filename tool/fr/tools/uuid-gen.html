Qu'est-ce qu'un UUID ?

UUID (Universally Unique Identifier) est un identifiant de 128 bits unique au monde.

Format : xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx
Version : v4 (basé sur l'aléatoire)
Probabilité de collision : pratiquement 0 (2^122 combinaisons)

Utilisé pour les clés de base de données, les tokens API, les noms de fichiers, etc.
