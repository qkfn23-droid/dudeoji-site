표준편차 계산기란?

숫자 목록의 평균(Mean), 분산(Variance), 표준편차(Standard Deviation)를 자동으로 계산합니다. 통계학 숙제, 데이터 분석, 품질 관리 등에 사용되는 필수 통계 도구입니다.

표준편차란?

표준편차는 데이터가 평균에서 얼마나 퍼져 있는지를 나타내는 수치입니다.

  • 표준편차가 작으면 — 데이터가 평균 근처에 모여 있음 (일관성 높음)
  • 표준편차가 크면 — 데이터가 평균에서 많이 떨어져 있음 (편차가 큼)

예: 시험 점수 {80, 82, 78, 81, 79}는 표준편차가 작고, {50, 100, 30, 90, 80}은 표준편차가 큽니다.

자주 묻는 질문

모표준편차와 표본표준편차의 차이는?

모표준편차는 N으로 나누고, 표본표준편차는 (N-1)로 나눕니다. 일반적으로 샘플 데이터를 분석할 때는 표본표준편차를 사용합니다.

소수점이 있는 숫자도 계산 가능한가요?

네, 정수와 소수 모두 입력 가능합니다. 결과도 소수점까지 정확하게 표시됩니다.
