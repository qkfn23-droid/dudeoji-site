각 항목 설명

  • 글자수 (공백 포함) — 띄어쓰기와 줄바꿈을 포함한 전체 문자 수입니다.
  • 글자수 (공백 제외) — 띄어쓰기, 탭, 줄바꿈 등 모든 공백을 제외한 문자 수입니다.
  • 단어수 — 공백을 기준으로 나뉜 단어의 수입니다.
  • 문장수 — 마침표(.), 느낌표(!), 물음표(?)로 끝나는 문장의 수입니다.
  • 줄수 — 줄바꿈(Enter)을 기준으로 나뉜 줄의 수입니다.
  • 바이트수 (UTF-8) — UTF-8 인코딩 기준 바이트 수입니다. 영문·숫자는 1바이트, 한글은 3바이트로 계산됩니다.

글자수 세기란?

글자수 세기 도구는 입력한 텍스트의 글자수, 단어수, 문장수, 줄수, 바이트수를 실시간으로 계산합니다. 자기소개서, 이력서, SNS 포스팅, 블로그 글 등 글자수 제한이 있는 곳에서 필수적인 도구입니다.

어디에 쓰나요?

  • 자기소개서/이력서 — 500자, 1000자 제한 확인
  • SNS 포스팅 — 트위터 280자, 인스타그램 2200자 제한
  • 블로그/SEO — 메타 설명 160자, 제목 60자 최적화
  • 학교 과제 — 레포트 글자수/단어수 요구사항 확인
  • 번역 — 원문과 번역문의 길이 비교

자주 묻는 질문

공백도 글자수에 포함되나요?

네, 기본적으로 공백을 포함한 글자수를 표시합니다. 공백을 제외한 글자수도 함께 표시되므로 필요에 따라 확인할 수 있습니다.

한글과 영어의 바이트 수가 다른가요?

네, 한글은 UTF-8 기준 한 글자당 3바이트, 영어는 1바이트입니다. SMS 발송이나 데이터베이스 저장 시 바이트 수가 중요합니다.

이모지도 글자수에 포함되나요?

네, 이모지도 1글자로 계산됩니다. 단, 바이트 수는 이모지마다 다를 수 있습니다 (보통 4바이트).
