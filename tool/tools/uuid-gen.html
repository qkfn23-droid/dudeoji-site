UUID란?

UUID (Universally Unique Identifier)는 전 세계에서 고유한 128비트 식별자입니다.

형식: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx
버전: v4 (랜덤 기반)
충돌 확률: 사실상 0 (2^122 가지)

데이터베이스 키, API 토큰, 파일명 등에 널리 사용됩니다.

UUID가 충돌할 확률은?

사실상 0입니다. UUID v4의 경우 경우의 수가 2^122(약 5.3 × 10^36)이라 겹칠 확률이 천문학적으로 낮습니다.
