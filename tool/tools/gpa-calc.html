학점 계산 방법

평균 학점(GPA)은 각 과목의 학점 수 × 성적 점수를 모두 더한 후, 총 이수 학점 수로 나누어 계산합니다.
F 학점은 GPA 계산에 포함되지만 취득 학점으로는 인정되지 않습니다.

계산식: GPA = Σ(과목 학점 × 성적 점수) ÷ Σ(과목 학점)

학점 계산기란?

과목별 학점과 성적을 입력하면 평균 학점(GPA)을 자동으로 계산합니다. 4.5점제와 4.0점제를 모두 지원하며, 과목을 자유롭게 추가하거나 삭제할 수 있습니다.

GPA 계산 방법

GPA = Σ(과목 학점 × 성적 점수) ÷ Σ(과목 학점)

  • 4.5점제 — A+ = 4.5, A = 4.0, B+ = 3.5, B = 3.0 ...
  • 4.0점제 — A+ = 4.0, A = 4.0, B+ = 3.5, B = 3.0 ...

자주 묻는 질문

P/F 과목도 포함되나요?

P/F(Pass/Fail) 과목은 일반적으로 GPA 계산에 포함되지 않습니다. 학점이 부여되는 과목만 입력하세요.

전체 학기 GPA를 계산하려면?

모든 학기의 과목을 한꺼번에 입력하면 전체 누적 GPA를 계산할 수 있습니다.
