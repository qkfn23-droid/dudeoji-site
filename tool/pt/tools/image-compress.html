O que é compressão de imagem?

A compressão de imagem é uma técnica que reduz o tamanho do arquivo mantendo ao máximo a qualidade visual.

JPG: Ideal para fotos. Com qualidade 75%, reduz de 60 a 80% do tamanho original.
WebP: Formato desenvolvido pelo Google. Até 25–35% menor que JPG.
PNG: Para imagens com fundo transparente. Menor taxa de compressão, mas sem perda de qualidade.

Esta ferramenta usa a Canvas API do navegador para processar as imagens. Como nenhuma imagem é enviada a servidores externos, suas fotos pessoais são comprimidas com total segurança.
