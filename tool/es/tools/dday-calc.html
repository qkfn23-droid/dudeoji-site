Calculadora de D-Day

Calcule la diferencia entre dos fechas o verifique el D-Day de una fecha específica.

-

Cómo usar la Calculadora de D-Day

Diferencia de fechas: Seleccione una fecha de inicio y una de fin para ver la diferencia en días, semanas, meses y años.

Cálculo de D-Day: Seleccione una fecha objetivo para calcular el D-Day desde hoy. Si es hoy, muestra D-DAY; si es futuro, D-número; si es pasado, D+número.
