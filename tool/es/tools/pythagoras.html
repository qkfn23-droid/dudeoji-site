Calculadora del Teorema de Pitágoras

Calcula la hipotenusa o el lado faltante de un triángulo rectángulo usando el teorema de Pitágoras (a² + b² = c²). Ingresa dos lados para encontrar el tercero.

Cómo funciona

  • Encontrar hipotenusa — Ingresa lados a y b: c = √(a² + b²)
  • Encontrar un lado — Ingresa hipotenusa c y lado a: b = √(c² - a²)

FAQ

¿Cuándo uso el teorema de Pitágoras?

Arquitectura, ingeniería, navegación, desarrollo de juegos — siempre que necesites la distancia entre dos puntos.
