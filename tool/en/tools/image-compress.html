What is Image Compression?

Image compression reduces file size while preserving as much visual quality as possible.

JPG: Best for photos. At 75% quality, typically 60–80% smaller than the original.
WebP: Google's modern format. 25–35% smaller than JPG at comparable quality.
PNG: Use when transparent backgrounds are needed. Lossless but larger file size.

This tool uses the browser's Canvas API to process images locally. Your images are never sent to an external server, so even personal photos can be compressed safely.
