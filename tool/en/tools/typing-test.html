Typing Speed Reference

WPM stands for Words Per Minute — the number of words typed correctly in one minute.

Beginner: ~20 WPM
Average: 40–60 WPM
Fast: 80–100 WPM
Professional: 120+ WPM

Accuracy matters too. Speed without accuracy is meaningless!
