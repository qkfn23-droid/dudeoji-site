Anleitung

Zahl ziehen — Geben Sie einen Bereich und die Anzahl ein, um zufällige Zahlen zu ziehen. Sie können wählen, ob Duplikate erlaubt sind.

Name auslosen — Geben Sie Namen ein (einen pro Zeile) und legen Sie die Anzahl der Gewinner fest, um zufällig auszulosen.

Münzwurf — Drücken Sie den Button, um zufällig Kopf oder Zahl zu bestimmen.

Häufige Fragen

Ist dieses Tool kostenlos?

Ja, 100% kostenlos. Keine Anmeldung nötig. Alles wird im Browser verarbeitet — keine Daten werden an Server gesendet.

Funktioniert es auf dem Handy?

Ja, alle Tools sind responsiv und funktionieren auf Smartphones, Tablets und Desktops.
