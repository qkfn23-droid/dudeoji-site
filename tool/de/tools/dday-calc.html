Anleitung zum D-Day-Rechner

Datumsunterschied: Waehlen Sie ein Start- und Enddatum, um die Differenz in Tagen, Wochen, Monaten und Jahren anzuzeigen.

D-Day-Berechnung: Waehlen Sie ein Zieldatum, um den D-Day ab heute zu berechnen. Heute = D-DAY, Zukunft = D-Zahl, Vergangenheit = D+Zahl.

Häufige Fragen

Ist dieses Tool kostenlos?

Ja, 100% kostenlos. Keine Anmeldung nötig. Alles wird im Browser verarbeitet — keine Daten werden an Server gesendet.

Funktioniert es auf dem Handy?

Ja, alle Tools sind responsiv und funktionieren auf Smartphones, Tablets und Desktops.
